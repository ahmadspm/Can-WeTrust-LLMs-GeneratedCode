# Can We Trust LLMs Generated Code?

### Security Evaluation Dataset for AI-Generated Source Code

![License](https://img.shields.io/badge/license-research-blue)
![Dataset](https://img.shields.io/badge/type-security_dataset-orange)
![Domain](https://img.shields.io/badge/domain-AI_security-green)
![Languages](https://img.shields.io/badge/code-multi_language-blue)

This repository contains a research dataset of source code generated by
Large Language Models (LLMs) for evaluating the **security, reliability,
and trustworthiness of AI-generated software**.

The dataset supports research in:

-   Secure code generation using LLM ICL security patterns
-   Vulnerability detection in AI-generated code
-   Evaluation of LLM programming assistants
-   AI-assisted software development security

The dataset was developed as part of the research study:

**"Can We Trust Large Language Models Generated Code? A Framework for
In-Context Learning, Security Patterns, and Code Evaluations Across
Diverse LLMs."**

------------------------------------------------------------------------

# Motivation

Large Language Models such as GitHub Copilot, ChatGPT, and other code
generation models are increasingly used to assist software development.
However, these models are trained on large public code repositories that
may contain insecure coding patterns and vulnerabilities.

Consequently, LLM-generated code may unintentionally introduce:

-   security vulnerabilities
-   insecure coding patterns
-   code quality issues
-   maintainability problems

This dataset enables researchers to systematically evaluate and
benchmark the **security risks of LLM-generated code**.

# Dataset Generation Workflow

Problem Tasks\
→ Prompt Engineering (Zero-shot / One-shot / Few-shot)\
→ LLM Code Generation\
→ Security Analysis (SAST + Manual Review)\
→ Vulnerability Labeling (CWE Categories)\
→ Dataset Creation

------------------------------------------------------------------------

# Prompting Strategies

### Zero-shot

The model receives only the problem description.

### One-shot

The model receives one example of secure code.

### Few-shot

The model receives multiple secure coding examples and patterns.

These strategies allow comparison of how **prompt engineering influences
the security of generated code**.

# Security Evaluation Metrics

The generated code was evaluated using:

-   Static Application Security Testing (SAST)
-   Manual security review
-   CWE vulnerability mapping
-   Code smell detection

Security scoring helps quantify the **risk level of AI-generated
software**.

# Intended Use

The dataset is intended for:

-   Research in AI security

-   Training secure code generation models

------------------------------------------------------------------------

# Ethical Considerations

This dataset intentionally contains **insecure code examples** for
research purposes.

Users should avoid deploying these code snippets in production systems
and use the dataset only for **research, testing, and security
analysis**.
